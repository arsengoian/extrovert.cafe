# authorized/

Тека лишилась як місце для публічних ключів, яких **немає** в акаунті
DigitalOcean. Зараз таких немає: ключі людей (`Arsen`, `Ihor`, `Roman`)
уже в акаунті, і terraform бере їх за іменем — див. `ssh_key_names` у
`variables.tf`. Ключ автоматики створює сам terraform із
`keys/extrovert_ed25519.pub`.

Прибрати доступ людині — прибрати імʼя зі змінної й перестворити дроплет:
DigitalOcean кладе ключі в `authorized_keys` лише під час створення, тож
на живому сервері файл треба чистити руками.
