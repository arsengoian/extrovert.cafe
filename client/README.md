# client — фронтенд для телефона

Те, що користувач відкриває, відсканувавши QR на стійці або на стаканчику.
Гейміфікація: вирощування кавенятка, монетки, бонуси, інфоматеріали.

Задум і механіки — `../docs/gamification.md`.

Стек: Vue + Vite, статика на Cloudflare Workers, дані з `api`, події з `ws`.

## Що врахувати з самого початку

- **Ідентифікатор точки в URL.** Перехід з кіоска приходить як
  `/?from=<point>` — щоб знати, де саме людина купила каву.
- **Офлайн.** Люди стоять біля автомата в підвалі ТРЦ. Стан кавенятка має
  переживати втрату мережі.
- **Без реєстрації на першому екрані.** Спершу показати кавенятко,
  акаунт просити потім — інакше відвалиться більшість.
