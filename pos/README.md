# pos — Worker точки й запасна сторінка кіоска

Cloudflare Worker, який обслуговує точки:

- **меню** кожної точки — окремий JSON у R2;
- **релізи стеку малини** — маніфест і архіви для `pi/stack/updater.sh`;
- **сторінку кіоска** `/p/<point>` — браузерну версію меню.

Прод-кіоск із 18.08.2026 — нативний `pos-native` на малині: він малює
меню сам і з цього Worker бере лише JSON і релізи. Браузерна сторінка
лишається **запасним** кіоском (відкат — `../pi/README.md`) і тим, що
відкривається з ПК, щоб подивитись меню.

**Прод:** https://pos.extrovert.cafe/p/kyiv-01

## Як влаштовано

```
public/            статика, яку віддає Worker
  index.html         каркас: сцена 1920×1080, лого вбудоване SVG (версія Б, 997×200)
                     лого сидить між маркерами <!-- logo:start --> / <!-- logo:end -->
  style.css          без CSS-змінних і grid; шрифти base64
  app.js             ES5: без стрілок, шаблонних рядків, const/let і fetch
src/index.js       Worker: роутинг точок, меню з R2, релізи для малини
data/prices.json   вихідний файл меню
scripts/push-prices.mjs  заливка меню в R2 (AWS SigV4 вручну, без залежностей)
scripts/embed-logo.mjs   вставка лого з design/ між маркерами в index.html
```

Сторінка перечитує меню **раз на хвилину** і повністю перезавантажується
**раз на годину**.

**Ці файли ніхто не генерує.** До серпня 2026 `design/logo/mk_menu2.py`
переписував `index.html` і `style.css` цілком — і одна команда з
`design/README.md` зносила все, що тут наживо. Тепер генератор робить лише
текстуру для 3D-макета, а кіоск правиться руками. Лого оновлюється точково:

```bash
node scripts/embed-logo.mjs ../../design/logo/versions/B/logo.svg
```

**Чому ES5.** Запасний кіоск мусить запуститись на Raspberry Pi 1 з
Chromium 65. Сучасний синтаксис там або не запуститься, або впаде мовчки. Те
саме про CSS: без змінних, без grid, без gap.

**Сцена 1920×1080 із `transform: scale()`.** Розкладка ідентична на 15,6" і на
21,5", бо масштабується вся сцена, а не окремі елементи.

## Параметри в URL — для замірів на слабкому залізі

| Параметр | Значення | Що робить |
|---|---|---|
| `?anim=0..4` | типово 1 | рівень анімацій: 0 нічого · 1 поява · 2 +дихання чашки · 3 +пара · 4 +блиск і пульс |
| `?hud=1` | вимкнено | лічильник fps, мінімального fps і найгіршого кадру в кутку |
| `?gpu=1` | вимкнено | виносить анімовані елементи в окремі шари (`backface-visibility`) |

Значення за замовчанням — `DEFAULT_ANIM` в `app.js`. **Вище 1 не піднімати:**
замір 17.08.2026 на Pi 1 дав 52 fps на `anim=1` і 0,5 fps при 100 % CPU на
`anim=2` (`../docs/roadmap.md`).

**Правило анімацій.** Нескінченних анімацій немає, одноразові можна. На
ARMv6 Raspbian примусово вимикає GPU-композитинг, тож навіть `transform` і
`opacity` коштують програмного перемальовування 1920×1080 на 700 МГц.
Статичні градієнти безпечні — вони малюються в шар один раз.

## URL

Схема з ідентифікатором точки — `../docs/urls.md`. Коротко:

```
/p/<point>                      сторінка
/api/v1/points/<point>/menu     меню
/releases/pi/<файл>             релізи для апдейтера на малині
```

Сторінка бере точку з `location.pathname`, тож один білд обслуговує всі точки.
Роут релізів уміє `If-None-Match` → `304` і `Range` → `206`: без першого
апдейтер качав би маніфест щоразу, без другого не докачав би обірваний архів.

## Заливка меню

```bash
node scripts/push-prices.mjs                  # kyiv-01
node scripts/push-prices.mjs kyiv-02 ./m.json # інша точка й файл
```

Ціни в каталозі Checkbox звіряє окремий скрипт — `checkbox/scripts/sync-prices.mjs`
(`../docs/checkbox.md`).
