# pos — меню-кіоск точки

Статика на Cloudflare Workers. Меню лежить у R2 окремим JSON на кожну точку,
сторінка перечитує його **раз на хвилину** і повністю перезавантажується
**раз на годину**.

**Прод:** https://pos.extrovert.cafe/p/kyiv-01

---

## Як влаштовано

```
public/            статика, яку віддає Worker
  index.html         каркас: сцена 1920×1080, лого вбудоване SVG (версія Б, 997×200)
  style.css          без CSS-змінних і grid; шрифти base64
  app.js             ES5: без стрілок, шаблонних рядків, const/let і fetch
src/index.js       Worker: роутинг точок + меню з R2
data/prices.json   вихідний файл меню
scripts/push-prices.mjs  заливка в R2 (AWS SigV4 вручну, без залежностей)
```

**Чому ES5.** Кіоск може крутитися на Raspberry Pi 1 з Chromium 2019 року.
Сучасний синтаксис там або не запуститься, або впаде мовчки. Те саме про CSS:
без змінних, без grid, без gap.

**Сцена 1920×1080 із `transform: scale()`.** Розкладка ідентична на 15,6" і на
21,5", бо масштабується вся сцена, а не окремі елементи.

## Параметри в URL — для замірів на слабкому залізі

| Параметр | Значення | Що робить |
|---|---|---|
| `?anim=0..4` | типово 2 | рівень анімацій: 0 нічого · 1 поява · 2 +дихання чашки · 3 +пара · 4 +блиск і пульс |
| `?hud=1` | вимкнено | лічильник fps, мінімального fps і найгіршого кадру в кутку |
| `?gpu=1` | вимкнено | виносить анімовані елементи в окремі шари (`backface-visibility`) |

Значення за замовчанням — `DEFAULT_ANIM` в `app.js`. Піднімати його вище 2
**тільки після заміру на самій малині**: порядок у `../pi/README.md`.

**Правило анімацій.** Рухаємо лише `transform` і `opacity`. На Pi 1 композитинг
іде процесором на 700 МГц, тож анімація `width`, `top`, `box-shadow` чи `filter`
означає перемальовування шару щокадру. Статичні градієнти безпечні — вони
малюються в шар один раз.

## URL

Схема з ідентифікатором точки — `../docs/urls.md`. Коротко:

```
/p/<point>                      сторінка
/api/v1/points/<point>/menu     меню
```

Сторінка бере точку з `location.pathname`, тож один білд обслуговує всі точки.

## Заливка меню

```bash
node scripts/push-prices.mjs                  # kyiv-01
node scripts/push-prices.mjs kyiv-02 ./m.json # інша точка й файл
```
