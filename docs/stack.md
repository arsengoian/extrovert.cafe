# Архітектура

```
             ┌───────────────┐        ┌──────────────┐
  Checkbox ─▶│  checkbox     │──┐     │   overseer   │──▶ Telegram
   (ПРРО)    │  вебхук+звірка│  │     │  лупа, звіти │
             └───────────────┘  │     └──────────────┘
                                ▼            ▲
                            ┌───────┐   ┌──────────┐
                            │ Redis │◀─▶│ Postgres │
                            └───────┘   └──────────┘
                                ▲            ▲
                    ┌───────────┴──┐   ┌─────┴──────┐
                    │      ws      │   │    api     │
                    │  події       │   │   REST     │
                    └──────┬───────┘   └─────┬──────┘
                           │                 │
              ┌────────────┴───┐     ┌───────┴────────┐
              │  pos (кіоск)   │     │ client (телефон)│
              │ CF Workers     │     │  CF Workers     │
              └────────────────┘     └─────────────────┘
```

## Сервіси

| Сервіс | Що робить | Порт |
|---|---|---|
| `api` | REST для client і pos: меню, профіль, кавенятка, бонуси | 3001 |
| `ws` | WebSocket: події точки й акаунта | 3002 |
| `checkbox` | приймає вебхуки ПРРО, звіряє пропущене | 3003 |
| `overseer` | telegram-бот, лупа, звіти в груповий чат | — |

## Дані

- **Postgres** — джерело істини: точки, чеки, акаунти, кавенятка, бонуси
- **Redis** — pub/sub між сервісами, сесії, rate limit
- **R2** — статика: меню точок, картинки, спрайти кавенят
- **GlitchTip** — помилки з усіх сервісів

## Фронтенди

Статика, деплой на Cloudflare Workers, спілкуються з `api` по REST і з `ws` по
вебсокету. Збірка Vue. Виняток — `pos`: там навмисно **ES5 без збірки**, бо
кіоск може крутитися на Raspberry Pi 1 з Chromium 2019 року. Див.
`docs/raspberry-pi.md`.

## Чого свідомо ще немає

- **Адмінка (Laravel Filament)** — поки нас двоє, у базу ходимо напряму
- **Черга завдань** — поки вистачає Redis pub/sub
- **Мультиарендність** — точки є, окремих власників немає
