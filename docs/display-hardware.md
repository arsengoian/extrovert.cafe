закупівлі не було в наявності — узятий замінник, **Asus VP227HF**. Причина
заміни суто «в наявності / нема», не «кращі характеристики», хоча за фактом
характеристики вийшли не гірші (нижче).

### Габарити (офіційний datasheet ASUS)

| | Ш | В | Г |
|---|---|---|---|
| **Без підставки** (як вішатимемо) | **492,7** | **291,3** | **57,5** мм |
| З підставкою | 492,7 | 363,8 | 204,4 мм |
| Активна площа матриці | 487,45 | 270,18 | — |
| Вага без підставки | 2,3 кг | | |
| Вага з підставкою | 2,6 кг | | |

**Перевірка на макеті:** над JL22 вільно 1008 − 675 = **333 мм**.
Корпус 291,3 мм влазить із запасом **41,7 мм** — навіть трохи більше, ніж
виходило з Lenovo (36 мм), бо цей корпус на 5,5 мм нижчий без підставки.
Глибина без підставки більша на 4,8 мм (57,5 проти 52,7) — на кронштейн під
нахилом це не критично, але враховувати при виборі кронштейна.

### Чому саме він

1. **Був у наявності, Lenovo — ні.** Пряма й головна причина заміни.
2. **4000:1 проти 1300:1.** Наше меню темне — цей параметр важливіший за
   яскравість, і тут заміна вийшла об'єктивно кращою.
3. **< 9,97 Вт проти 11 Вт.** Той самий важіль, що й з Lenovo (менше тепла
   на електроліти блока живлення при 24/7) — тут навіть трохи краще.
4. Той самий VESA 100×100 і ті самі входи (HDMI+VGA) — план монтажу з
   кронштейном не міняється.
5. **Застереження, яке варто перевірити наживо:** матриця **VA**, не IPS,
   як планувалось у Lenovo. Datasheet заявляє ті самі 178°/178°, але VA-панелі
   на практиці частіше «пливуть» контрастом і кольором при погляді збоку
   сильніше за IPS — це не видно з характеристик, тільки з живого перегляду
   під кутом, під яким реально стоятимуть клієнти біля кіоска. Поки не
   позначено як проблему, лише як відкрите питання до монтажу.

## Що зробити перед монтажем

- [ ] Купити 2 шт Asus VP227HF (90LM0880-B01O71)
- [ ] Кронштейн VESA 100×100 — стельовий, під нахил ~6° (та сама модель, що й
      планувалась під Lenovo, глибина на 4,8 мм більша — перевірити перед покупкою)
- [ ] Гасити підсвітку вночі: `vcgencmd display_power 0` по крону на Pi
- [ ] Зсув пікселів у `kiosk` — проти вигорання статичного меню
- [ ] Не замуровувати в глухий короб: +10 °C ≈ удвічі коротший ресурс електролітів
- [ ] Перевірити кути огляду наживо (VA-застереження вище) під реальним кутом
      підходу клієнтів, перед фінальним монтажем на кронштейн
- [x] Pi переведено на 1080p (`hdmi_group=1 / hdmi_mode=16`) ✅ 09.08.2026
- [x] Повний діапазон RGB (`hdmi_pixel_encoding=2`) ✅ 09.08.2026
