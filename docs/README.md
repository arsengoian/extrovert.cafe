# Документація

Реєстр доків. З нього збирається `data-map.html` (`bun run docs:map`): групи
й порядок тут — це групи й порядок меню на сторінці. Новий док — рядок у
потрібну групу, інакше `bun run docs:map:check` не пройде. Док, який
перестав бути правдою, не «архівується» поруч із чинними — його вміст
переносять у той док, що його замінив, і файл видаляють: історія лишається
в git, а в теці не лишається двох відповідей на те саме питання.

## Архітектура й дані

| Файл | Про що |
|---|---|
| `services.md` | повна карта: хто де крутиться, як спілкується, як автентифікується, що з цього вже існує |
| `db-schema.md` | схема Postgres (ER-діаграми), ключі й канали Redis, міграції на dbmate, сіди контенту в JSON |
| `urls.md` | схема URL і навіщо ідентифікатор точки з першого дня |
| `deploy.md` | куди і чим викочується застосунок, бекенд і меню; що робиться руками один раз |
| `checkbox.md` | ПРРО Checkbox: токен касира, вебхук, підпис, каталог товарів |
| `video.md` | камера, буфер на точці, R2, два дроплети, обробка відео |
