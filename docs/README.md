# Документація

| Файл | Про що |

| `urls.md` | схема URL і навіщо ідентифікатор точки з першого дня |

| `checkbox.md` | ПРРО Checkbox: вебхук, підпис, товари, що з ним робити |

| `admin_panel.md` | що має бачити оператор: здоровʼя, статистика, операційка |
| `raspberry-pi.md` | що крутиться на малині (діаграма), деплой релізу від коміту до екрана, перехід на стек, overlay |
| `../pi/stack/README.md` | нутрощі стеку: розкладка, кроки апдейтера, overlap-підміна |
| `display-hardware.md` | обраний монітор Lenovo L22-4e і чому саме він |
| `video.md` | камера, буфер на точці, R2, два дроплети, обробка відео |
| `sprite_generation_plan.md` | як робимо спрайти напоїв |
