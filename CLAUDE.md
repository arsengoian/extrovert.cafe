# CLAUDE.md

Інструкції для Claude у цьому репозиторії. Тримати коротким: усе, що тут
написано, читається на початку кожної сесії.

## Коміти

**Мова — англійська. Формат — Conventional Commits.**

```
<type>(<scope>): <опис у наказовому способі, з малої, без крапки>

<тіло: ЧОМУ, а не що. Що видно з дифу.>
```

Типи: `feat` · `fix` · `refactor` · `docs` · `chore` · `test` · `perf` · `build`

Скоупи за теками: `pos` · `api` · `ws` · `checkbox` · `overseer` · `pi` · `docker`

```
feat(pos): add cup animations selectable via ?anim
fix(pos): load style.css and app.js from absolute paths
docs: add video capture and processing architecture
```

Правила, які легко порушити:
- рядок теми — до 72 символів, у наказовому способі: `add`, а не `added`;
- у тілі пояснювати причину й наслідок, а не переказувати диф;
- якщо коміт щось ламає — `BREAKING CHANGE:` окремим абзацом у кінці.

Не пушити без прямого прохання. `origin/main` уже опублікований — коміти
до нього історію не переписувати.

## Межі, які вже ламали

**`design/` поза git, `code/` під git.** Жоден генератор із `design/` не має
права писати в `code/`. `mk_menu2.py` колись переписував `pos/public/index.html`
і `style.css` цілком — і одна команда з `design/README.md` зносила живий код із
неверсійованої теки. Тепер він робить лише текстуру для 3D-макета. Лого
вставляється точково: `node scripts/embed-logo.mjs`.

**Кіоск — ES5 і CSS без сучасностей.** `pos/public/*` крутиться на Raspberry Pi 1
(ARMv6, 512 МБ, Chromium 65). Без стрілок, шаблонних рядків, `const`/`let`,
`fetch`. У CSS без змінних, `grid` і `gap`. Це не смак, це «інакше сторінка
мовчки не запуститься».

**Нескінченних анімацій на кіоску немає.** Не «тільки `transform`/`opacity`» —
цього замало. Raspbian на ARMv6 примусово додає `--disable-gpu-compositing`, GPU
не задіяний узагалі, і `transform` коштує як `top`: програмний перемальовок
1920×1080 на 700 МГц. Замір 17.08.2026: вічна `transform`-анімація на 12
елементах — 0,5 fps і 100 % CPU; одноразова — 52 fps. Одноразові можна,
нескінченні ні. Статичні градієнти безпечні.

**Статика підключається абсолютними шляхами.** Сторінка живе на `/p/<point>`,
тож відносний `style.css` браузер попросить як `/p/style.css`, а Worker
відповість `400 bad point id`.

## Документація

Українською, як решта `docs/`. Пояснювати причину рішення, а не лише результат —
у цьому репозиторії README читають, щоб не повторити чужі граблі.

**`docs/data-map.html` — згенерований, руками не редагується.** Джерело —
`docs/db-schema.md` і `docs/services.md`. Після правки будь-якого з них:
`npm run docs:map` і комітити html **в тому ж коміті**, що й док.
`npm run docs:map:check` дає код 1, якщо забули, або якщо ER-синтаксис битий
(так ловиться `FK UK` через пробіл замість коми — mermaid такого не малює).
У Claude Code перезбірку робить PostToolUse-хук з `../.claude/settings.json`,
але artifact на claude.ai сам не оновлюється — перепублікувати окремо.
Глибина меню сторінки задається заголовками `##`/`###` у самих доках.
