# CLAUDE.md

Інструкції для Claude у цьому репозиторії. Тримати коротким: усе, що тут
написано, читається на початку кожної сесії.

## Коміти

**Мова — англійська. Формат — Conventional Commits.**

```
<type>(<scope>): <опис у наказовому способі, з малої, без крапки>

<тіло: ЧОМУ, а не що. Що видно з дифу.>
```

Типи: `feat` · `fix` · `refactor` · `docs` · `chore` · `test` · `perf` · `build`

Скоупи за теками: `pos` · `api` · `ws` · `checkbox` · `overseer` · `pi` · `docker`

```
feat(pos): add cup animations selectable via ?anim
fix(pos): load style.css and app.js from absolute paths
docs: add video capture and processing architecture
```

Правила, які легко порушити:
- рядок теми — до 72 символів, у наказовому способі: `add`, а не `added`;
- у тілі пояснювати причину й наслідок, а не переказувати диф;
- якщо коміт щось ламає — `BREAKING CHANGE:` окремим абзацом у кінці.

Не пушити без прямого прохання. `origin/main` уже опублікований — коміти
до нього історію не переписувати.

## Межі, які вже ламали

**`design/` поза git, `code/` під git.** Жоден генератор із `design/` не має
права писати в `code/`. `mk_menu2.py` колись переписував сторінку кіоска
цілком — і одна команда з `design/README.md` зносила живий код із
неверсійованої теки. Тепер він робить лише текстуру для 3D-макета.

**Кіоск на точці один — нативний `pos-native` (C, Cairo, GLES2, dispmanx).**
Браузера на малині немає: ні прод, ні запас, ні сторінка, яку можна відкрити.
Запасний варіант — статична картинка через `fbi` (`docs/raspberry-pi.md` §6).
Правила під HTML-кіоск (ES5, абсолютні шляхи, заборона вічних анімацій) разом
із ним і пішли — лишились у git.

**Малина нічого не компілює.** ARM-бінарник збирається на ПК у контейнері
(`pos-native/docker/make-pi.sh`), на точку їде готовий архів релізу. `make pi`
на самому пристрої — 80 с при 100 % CPU, і всі 80 с меню смикається на очах
у клієнта.

**Меню й релізи лежать у публічному бакеті R2** (`pos.extrovert.cafe`), сервера
між точкою й файлами немає. Нове меню — `bun run --filter @extrovert/pos prices:push`, новий
реліз — `bun run --filter @extrovert/pos release:push` (архів першим, маніфест останнім).

**Скрізь `bun`, ніде `npm`** (20.09.2026). `bun` — і рантайм сервісів, і
раннер скриптів, і менеджер пакетів; у репозиторії один `bun.lock`.
Команда у воркспейсі — `bun run --filter @extrovert/<пакет> <скрипт>`.
Чому саме так — `docs/services.md` §2.

## Документація

Українською, як решта `docs/`. Пояснювати причину рішення, а не лише результат —
у цьому репозиторії README читають, щоб не повторити чужі граблі.

**`docs/data-map.html` — згенерований, руками не редагується.** На сторінці —
усі доки з реєстру `docs/README.md` (групи й порядок звідти ж). Новий док —
рядок у групу реєстру. Док, який перестав бути правдою, не лишається лежати
поруч із чинними: його вміст переносять у той док, що його замінив, прибирають
посилання й видаляють файл — історія лишається в git.
Після правки будь-якого дока реєстру: `bun run docs:map` і комітити html
**в тому ж коміті**, що й док. `bun run docs:map:check` дає код 1, якщо
забули, якщо док із `docs/` не записаний у реєстр, або якщо ER-синтаксис
битий (так ловиться `FK UK` через пробіл замість коми — mermaid такого не
малює). У Claude Code перезбірку робить PostToolUse-хук з
`../.claude/settings.json`, але artifact на claude.ai сам не оновлюється —
перепублікувати окремо. Кожен док починається з `# Назви` — вона йде в меню;
глибина меню задається заголовками в самих доках.
